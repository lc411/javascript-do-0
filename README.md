## 🎯 Objetivos do Curso

- ✅ Entender conceitos básicos de JavaScript
- ✅ Trabalhar com manipulação de DOM
- ✅ Usar eventos e interatividade
- ✅ Implementar estruturas de controle (if-else, switch, loops)
- ✅ Criar funções reutilizáveis
- ✅ Usar arrays e estruturas de dados
- ✅ Aplicar recursão e iteração

## 💻 Tecnologias Utilizadas

- **HTML5** - Estrutura dos documentos

- **DOM API** - Manipulação de elementos

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/lc411/javascript-do-0.git
```

2. Navegue até o projeto:
```bash
cd javascript-do-0
```

3. Abra os arquivos HTML em um navegador ou use a extensão Live Server:
   - Clique com botão direito em um arquivo `.html`
   - Selecione "Open with Live Server"
